# Bingo Go 主应用全页面重设计实施计划

## 目标

- 将会话、团队、设置、小游戏中心、命令面板及所有加载/空白/错误状态统一为专业 Agent 工作台。
- 保留当前 app-server、IPC、设置仓库和游戏包能力，不修改共享 wire schema，不重做三个独立小游戏。
- 以当前未提交工作树为基线增量实现，不恢复已删除的旧设置页面，也不覆盖其他进行中的改动。

## 页面结构

1. 全局窄导航栏承载会话、团队、小游戏、命令、工作区和设置入口。
2. 会话页使用会话侧栏、任务流和可折叠 Inspector；窄窗口将两侧面板收进 Drawer。
3. 团队页使用全宽资源工作台，通过成员、房间、任务和投递四个视图浏览现有资源。
4. 设置页使用分组侧边导航，包含运行设置、Provider、MCP、个人资料、外观、通知和小游戏七个分区。
5. 小游戏中心保留为快捷弹层，并可精准跳转到小游戏设置分区。

## 视觉与交互

- 使用中性灰阶、品牌青绿、信息蓝和风险珊瑚红；保留用户自定义强调色、明暗主题、界面密度和减少动效偏好。
- 页面保持平面、紧凑和可扫描；卡片只用于独立操作对象，圆角不超过 8px，阴影仅用于浮层和 Composer。
- 主会话使用 composer submit；Agent 私聊和房间使用 send prose，并隐藏 Shell 与运行配置控制。
- 设置分区切换前保护未保存状态；危险操作继续通过确认框显式确认。

## 验证

- 组件测试覆盖导航、提交分流、运行配置、团队资源、设置脏状态、小游戏跳转和命令面板键盘操作。
- 执行 `npm run typecheck`、`npm test` 和 `npm run build`。
- 使用仅开发态启用的 UI fixture 做有限视觉检查：1180x760 明亮主题全页面、1600x900 暗色关键页、800x600 明暗主题响应式页面与浮层。
